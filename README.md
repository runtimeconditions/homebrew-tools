# Runtime Conditions Homebrew tap

```sh
brew tap runtimeconditions/tools
brew install rc
```

`brew install rc` also installs `rc-profiler-go`, the Go profiler. Other profilers are installed with
their own package managers, for example `npm install --save-dev @runtimeconditions/typescript-profiler`,
and `rc profile <language>` finds them on `PATH`.

The formulas are generated by the release workflow of
[`go-rc-cli`](https://github.com/runtimeconditions/go-rc-cli) and attached to each release. The
`Update formulas` workflow here copies them from the latest release every hour, or on demand from the
Actions tab, and commits the change with the repository's own token, so no personal access token or
secret is involved. Do not edit the formulas by hand.
